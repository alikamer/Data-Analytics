# Data Analytics & Data Science Bootcamp Projects

This repository contains my projects, scripts, and notes from the **Miuul Data Scientist Bootcamp**. It is primarily organized for educational purposes and tracks my progress throughout the curriculum.

## 🗂️ Folder Structure

The repository is organized into distinct modules reflecting the bootcamp curriculum:

- **`Feature_Engineering/`**: Contains scripts and notes on data preprocessing, feature extraction, and feature engineering techniques.
- **`Machine_Learning/`**: Includes foundational and advanced machine learning models (Linear/Logistic Regression, KNN, CART, Advanced Trees) and unsupervised learning examples, along with case studies (e.g., Telco Churn Prediction, Diabetes Prediction).

## 🚀 About the Bootcamp

The Miuul Data Scientist Program is an intensive bootcamp covering real-world data science practices, machine learning algorithms, and data analytics pipelines. The contents of this repository demonstrate hands-on implementations of the concepts taught during the course.

## 📝 Notes
- Datasets, temporary IDE files, and large model binaries (`.pkl`) are excluded from version control via `.gitignore` to keep the repository clean.
- The scripts include both theoretical notes and practical Python implementations.
